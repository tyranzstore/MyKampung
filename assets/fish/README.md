# TYRANZ — Koleksi Ikan Laut Malaysia (30 model)

30 separate GLB 2.0 fish models for Three.js. Stylized approximations, not exact zoological reconstructions. All geometry and vertex colors embedded. Each fish points toward +X, Y up. Units are game-relative.

Names are Malaysian Malay common names, some covering multiple species; coastal and brackish-water fish included. For production taxonomy see Malaysia Department of Fisheries Valid Local Name of Malaysian Marine Fishes.

Example: `loader.load("assets/fish/Ikan_Kembung.glb", gltf => scene.add(gltf.scene));`

No animation clips. Animate swim by moving/rotating models in Three.js.
