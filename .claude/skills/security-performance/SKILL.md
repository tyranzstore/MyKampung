# Universal Security & Performance

## Security
- Identify trust boundaries, authentication/authorization, input validation and data exposure.
- Apply least privilege, secure session handling and server-side verification for payments and entitlements.
- Never commit or reveal secrets; use environment configuration and rotation guidance.
- Avoid destructive scans or production penetration tests without explicit authorization.
- Review third-party dependencies and data retention/privacy needs.

## Performance
- Measure before optimizing; capture baseline and repeatable test conditions.
- Investigate network payloads, rendering, memory, database queries and cache behavior.
- Make targeted changes and document tradeoffs, regressions and measurement limits.

## Reporting
- Rank findings by impact and likelihood; distinguish verified findings from suggestions.
- Include mitigation, tests actually run and follow-up checks.
