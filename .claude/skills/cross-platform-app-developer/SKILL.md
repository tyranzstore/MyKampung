# Universal Cross-Platform App Developer

## Discovery
- Inspect existing framework, rendering technology, platform targets and native requirements.
- Determine whether PWA, Capacitor, React Native, Flutter or another approach fits existing code; do not impose one.

## Implementation
- Keep shared business logic separate from platform-specific adapters.
- Design for touch, keyboard, safe areas, screen sizes, offline/error states and accessibility.
- Account for app lifecycle, permissions, deep links and storage behavior.
- Test on real target devices; browser success alone is not native-app validation.
- Follow applicable app-store rules for digital purchases, privacy and disclosures.

## Quality
- Document build/signing prerequisites, native dependencies and test coverage.
- Never embed API secrets in app packages.
- Provide a platform-specific release checklist and unresolved risks.
